# Student Performance Tracker

## Overview

A basic student performance analysis project using Microsoft Excel and MySQL.

The project contains student details and test scores, with basic analysis performed using Excel and SQL queries.

## Tools Used

- Microsoft Excel
- MySQL

## Excel Analysis

The Excel file is used to organize and analyze student performance data, including:

- Student details
- Test scores
- Basic calculations
- Performance comparison

## MySQL Analysis

The SQL file contains queries for working with the student performance database, including:

- Database and table creation
- Inserting student records
- Filtering records using `WHERE`
- Sorting using `ORDER BY`
- Grouping using `GROUP BY`
- Filtering grouped results using `HAVING`
- Aggregate functions such as `COUNT`, `MAX`, `MIN`, `AVG`, and `SUM`
- `DISTINCT`
- Conditional filtering using `AND`, `OR`, and `NOT`
- `BETWEEN`
- `IN`
- Pattern matching using `LIKE`

## Project Files

| File | Description |
|---|---|
| `Student_performance_tracker.xlsx` | Student performance data and Excel analysis |
| `Students_queries.sql` | MySQL database, data insertion, and analysis queries |

This project helped me build a practical foundation in:

- Microsoft Excel for basic data analysis
- MySQL for querying and analyzing data
- Working with structured student performance data
- Using SQL filtering, sorting, grouping, and aggregate functions
